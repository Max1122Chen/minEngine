## Configure / build

Set `ENGINE_ROOT` to the minEngine **repository** root (the folder that contains the `minEngine/` CMake tree).

Use the **same CMake generator/toolchain** as your engine tree (this repo typically uses MinGW Makefiles or Ninja + MinGW). A bare `cmake -S . -B build` on Windows may pick Visual Studio and fail without `/utf-8` unless the engine CMake applies it.

```powershell
cmake -S . -B build -G "MinGW Makefiles" -DENGINE_ROOT="{{ENGINE_ROOT}}"
cmake --build build --target {{PROJECT_EDITOR_NAME}} {{PROJECT_NAME}}
cmake --build build --target package-{{PROJECT_NAME}}
```

Output binaries go to `bin/` under this project. Open the `.meproject` with MaximumEditor or your project editor exe.
